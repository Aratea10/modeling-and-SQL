Ejercicios y prácticas de **modelado de bases de datos** y **scripting SQL** del Bootcamp de Desarrollo Web FullStack en [KeepCoding](https://keepcoding.io/). Incluye diseño de esquemas entidad-relación y su implementación en PostgreSQL, con casos prácticos como un **Videoclub** y una **Academia**.

---

## ✨ Contenido

### 🗄️ Diseño de Bases de Datos

- **DDL** — Modelado visual con Draw.io
- **Normalización** — Estructuración eficiente de datos
- **Restricciones** — `NOT NULL`, `UNIQUE`, `CHECK`, `DEFAULT`
- **Esquemas** — Organización lógica con `CREATE SCHEMA`

---

## 🔧 Tecnologías utilizadas

- **PostgreSQL** — Base de datos relacional
- **SQL (ANSI)** — Lenguaje de consultas
- **Draw.io** — Diagramas entidad-relación
- **DBeaver** — Cliente SQL

## 🚀 Cómo ejecutar

### Prerrequisitos

- **PostgreSQL** instalado (o acceso a un servidor remoto)
- Un cliente SQL como **DBeaver**, **pgAdmin** o la extensión de VS Code

### Ejecución

1. Clonar el repositorio:
   `git clone https://github.com/Aratea10/modeling-and-SQL.git`

2. Abrir el script deseado (ej: `práctica-videoclub/script_videoclub.sql`)
3. Conectar a tu instancia de PostgreSQL y ejecutar el script
